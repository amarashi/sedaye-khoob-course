A student testimonial card — big quote, author + role, optional side illustration.

```jsx
<Testimonial
  quote="«برای اولین بار فهمیدم فاصله‌ها فقط اسم نیستند.»"
  name="یارا گیگیلی" role="هنرجوی پیانو"
  art="assets/design/testimonial-piano.png" accent="indigo" />
```

`accent` recolours the tick + tint (`indigo | crimson | gold | magenta`).
