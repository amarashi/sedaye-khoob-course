The signature circular spotlight that frames an ostad / instrument illustration on a soft glow.

```jsx
<InstrumentOrb src="assets/design/ostad-piano.png" title="نت‌ها" caption="نت‌ها را مثل مختصات بخوانید" size={220} />
```

Set `float` (default true) for the gentle hover-float, `size` for diameter. Drop `title`/`caption` for a bare orb.
