Compact kicker / status pill. Use for the price kicker, section eyebrows, or small statuses.

```jsx
<Badge tone="gold" dot>دوره آنلاین</Badge>
<Badge tone="indigo">۱۲ فصل آموزشی</Badge>
```

Tones: `indigo`, `crimson`, `gold`, `night` (for dark surfaces), `neutral`. Set `dot` for a leading status dot.
