A pill-shaped, RTL-aware action button — use for every primary/secondary call to action across Sedaye Khoob.

```jsx
<Button variant="gold" size="lg">خرید دوره تئوری موسیقی</Button>
<Button variant="secondary" arrow>دیدن درس‌ها</Button>
```

Variants: `gold` (the high-energy hero CTA, gold fill + warm glow), `primary` (indigo fill), `secondary` (surface with a strong outline), `ghost` (indigo text only). Sizes `sm | md | lg`. Set `arrow` for the start-ward chevron, `href` to render as an `<a>`, or `iconStart` for a leading icon. Hover/press states are handled by the bundled `.sk-btn` CSS.
