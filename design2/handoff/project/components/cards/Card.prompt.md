The brand's stadium-radius surface container — wrap course summaries, checkout panels, feature blocks.

```jsx
<Card variant="surface"><h3>تئوری موسیقی</h3></Card>
<Card variant="night">...checkout summary...</Card>
<Card variant="spectrum">...featured...</Card>
```

Variants: `surface` (light, default), `raised` (heavier shadow), `night` (deep-indigo, light text — pair with `Checklist tone="gold"`), `spectrum` (gradient top edge). `pad` is `sm | md | lg`.
