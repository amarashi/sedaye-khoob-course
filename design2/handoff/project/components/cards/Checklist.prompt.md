Benefit / feature list with the brand's circular check marks.

```jsx
<Checklist items={["دسترسی دائمی به دوره","درس‌های ویدیویی و فایل تمرین"]} />
<Checklist tone="gold" boxed items={[...]} />  /* on a night Card */
```

`tone` colours the check chip (`crimson` default, `indigo`, `gold`). Set `boxed` for the checkout-style framed rows.
